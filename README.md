# Explainable and Externally Validated Machine Learning for Chronic Kidney Disease Classification

Code and results for the paper:

> K. Agrawal, S. Jain, R. Mahajan, A. Grover and R. Adlakha, "Explainable and Externally Validated Machine Learning for Chronic Kidney Disease Classification," *IAES International Journal of Artificial Intelligence (IJ-AI)*, under review.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/17SdOubHAb1zg0s4Ec5uro73As2LyitqO?usp=sharing)

## Overview

The study compares five classical machine learning models (Logistic Regression, SVM, Random Forest, Gradient Boosting, AdaBoost) and five deep learning models for tabular data (MLP, ResNet, 1D-CNN, TabNet, FT-Transformer) for binary CKD classification.

- **Development cohort:** UCI Chronic Kidney Disease dataset (ID 336), 400 patients, 24 features
- **External cohort:** NHANES 2015–2016 and 2017–March 2020, 11,885 adults with complete data on 14 shared features; CKD defined as eGFR < 60 mL/min/1.73 m² (CKD-EPI 2021)
- **Statistics:** DeLong 95% confidence intervals, McNemar's and DeLong's pairwise tests with Bonferroni correction
- **Explainability:** SHAP (Tree and Gradient explainers), TabNet attention masks, LIME, permutation importance, PDP, ICE, PCA decision boundary, consensus ranking with Kendall's W
- **Feature ablation:** Random Forest with the top-3, 5, 8, 12 and all 24 consensus-ranked features

## Main results

| | Result |
|---|---|
| UCI hold-out accuracy (n = 80) | 88.8% (TabNet) to 100% (SVM, MLP, FT-Transformer) |
| UCI 5-fold CV AUC | 0.993 to 0.999 |
| Pairwise differences | None significant after Bonferroni correction |
| NHANES external AUC (no re-training) | 0.714 to 0.816; best Gradient Boosting 0.816 (95% CI 0.802–0.830) |
| XAI consensus top features | Urine specific gravity, packed cell volume, urine red blood cells, albumin, hemoglobin |
| Agreement between XAI methods | Kendall's W = 0.736 |

## How to run

### Google Colab (recommended)

1. Open `CKD_Explainable_ML_Pipeline.ipynb` in Colab, or use the badge above.
2. Select **Runtime → Change runtime type → T4 GPU**.
3. Select **Runtime → Run all**.

Both datasets are downloaded automatically: UCI through `ucimlrepo`, NHANES from the CDC website. Results are saved to `MyDrive/CKD_XAI_results` if Google Drive is mounted, otherwise to `/content/CKD_XAI_results`. A full run takes a while because of the hyperparameter searches; set `FAST = True` in the configuration cell for a quick functional test (the numbers will not match the paper).

### Local

```bash
pip install -r requirements.txt
jupyter notebook CKD_Explainable_ML_Pipeline.ipynb
```

Set the environment variable `CKD_OUT` to choose the output folder. If the automatic downloads fail, set `UCI_CSV` and `NHANES_LOCAL_DIR` in the configuration cell to local copies of the data.

## Reproducibility

- Random seed 42 for all libraries; two independent Colab runs gave identical results.
- Hyperparameters were tuned on the 320-record training set only; imputation and scaling are fitted inside each training fold.
- Software versions used for the reported results: Python 3.13, scikit-learn 1.6.1, PyTorch 2.14, pytorch-tabnet 4.1.0, SHAP 0.54.1. The notebook saves the versions of each run to `software_versions.txt`.

## Limitations

The cross-validated AUCs reuse hyperparameters tuned on the training partition and may be slightly optimistic. The NHANES outcome is defined from creatinine-based eGFR, which overlaps with the creatinine predictor; a sensitivity analysis without creatinine is included (AUC 0.769–0.779 for RF and LR). See the paper for the full list.
